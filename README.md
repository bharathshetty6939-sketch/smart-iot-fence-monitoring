# Smart IoT Fence Monitoring & Control System

An integrated IoT safety and perimeter control system featuring an ESP32/Arduino embedded system paired with a custom MIT App Inventor Android application for real-time monitoring and alert handling.

## ⚡ Key Features
- **Live Perimeter Status Monitoring:** Real-time feedback from hardware fence sensors displayed on the mobile interface.
- **Remote Actuation & Control:** Relay/alarm toggles directly operated via the mobile app over Wi-Fi/Bluetooth.
- **Automated Intrusion Alerts:** Instant event notifications dispatched when fence breach or tampering is detected.
- **Smart Status Indicators:** Visual indicators in-app for active monitoring, warning, and emergency states.

## 🛠️ Tech Stack & Hardware
- **Hardware/Microcontroller:** ESP32 / Arduino, Perimeter Sensors, Relay Modules, Buzzer
- **Mobile App Platform:** MIT App Inventor (Block-Based UI & Logic)
- **Communication Protocol:** Bluetooth Serial / Wi-Fi (HTTP/MQTT)
- **Target OS:** Android
